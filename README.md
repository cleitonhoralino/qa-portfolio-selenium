# 🚀 QA Portfolio - Selenium Automation

Projeto de automação web desenvolvido com Python + Selenium com foco em testes automatizados E2E, interação com elementos dinâmicos e simulação de fluxos reais de usuário.

---

# 📌 Objetivo

Este projeto foi criado com o objetivo de praticar e demonstrar conhecimentos em:

* Automação de testes web
* Selenium WebDriver
* Navegação entre páginas e abas
* Interação com formulários
* Manipulação de elementos dinâmicos
* Esperas explícitas (WebDriverWait)
* Scroll automatizado
* Tratamento de popups
* Fluxos End-to-End (E2E)
* Estruturação de cenários automatizados

---

# 🛠️ Tecnologias Utilizadas

* Python 3
* Selenium WebDriver
* Google Chrome
* ChromeDriver

# ▶️ Fluxo Automatizado

A automação realiza:

✅ Abertura do navegador

✅ Navegação até o site

✅ Clique em elementos da página

✅ Busca e interação com múltiplos elementos

✅ Troca de abas do navegador

✅ Preenchimento automatizado de formulário

✅ Scroll automático até elementos

✅ Espera inteligente com WebDriverWait

✅ Clique via JavaScript

✅ Tratamento de popup

✅ Validação de URL

✅ Encerramento automatizado do navegador

# 💻 Como Executar

## 1. Clonar o repositório

```bash
git clone https://github.com/cleitonhoralino/qa-portfolio-selenium.git
```

---

## 2. Acessar a pasta do projeto

```bash
cd qa-portfolio-selenium
```

---

## 3. Instalar dependências

```bash
pip install selenium
```

---

## 4. Executar automação

```bash
python cofigo_selenium.py
```
